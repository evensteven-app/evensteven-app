# Security Policy

Thanks for helping keep EvenSteven safe. We take security seriously and appreciate responsible disclosure.

## Scope

This policy covers this public repository. Note that premium/subscription functionality lives in a separate closed-source core package (`EvenSteven.Core`) — please also report issues related to that functionality even though the code is not public here.

## Reporting a vulnerability

**Do not open a public issue.** Report privately instead:

- Use [GitHub Private Advisories](https://github.com/evensteven-app/evensteven-app/security/advisories/new) (preferred), or
- Open a [security issue](https://github.com/evensteven-app/evensteven-app/issues) and mark it **confidential**, or
- Direct message the maintainers via [Discussions](https://github.com/evensteven-app/evensteven-app/discussions).

Please include:

- The affected endpoint / module / API endpoint,
- A minimal reproducer (steps, requests, payloads),
- The impact you believe it has (data exposure, privilege escalation, brute-force bypass, etc.),
- Your suggested fix, if you have one.

## What to expect

- Acknowledge receipt within **3 business days**.
- Assessment and follow-up within **10 business days**.

We do not pay bounties at this time.

## Safe areas

- This project is a non-commercial open-core app; there is no third-party hosted service to attack.
- Local development instances contain no real user data.

Thank you for being part of the community.
