## Никаких таблиц и переписок

**НаБрата** считает, кто кому сколько должен. Никаких регистраций, никаких установок, никакой рекламы. Откройте браузер — через 10 секунд комната готова. Работает на телефоне и компьютере, с живой синхронизацией между всеми участниками.

> Между своими не нужны юристы и расписки. Достаточно честного слова и приложения, которое не даст запутаться в суммах. **«НаБрата»**: честный алгоритм для честной дружбы.

---

## Как это работает

**1. Создайте комнату**

Нажмите кнопку на главной — и получите три вещи:
- **Общая ссылка** — кидайте в групповой чат. Все видят баланс, но не могут редактировать.
- **Редакторская ссылка** — оставьте себе. Только с ней можно управлять участниками и настройками комнаты.
- **Пароль комнаты** — включите, если нужна защита от чужих изменений.

**2. Добавьте людей**

Введите имена участников. «НаБрата» выдаёт каждому персональный ключ. Отправьте в личные сообщения — и больше не нужно думать, кто что вносил.

**3. Делите траты и следите за балансом**

- Накиньте одному: «Вася заплатил за такси 800 рублей».
- Разделите на всех: «Ужин 5000 рублей — поровну между выбранными».
- Смотрите баланс в реальном времени. Два человека вносят траты с разных телефонов — данные синхронизируются мгновенно.

## Возможности

- **Комната по ссылке.** Никаких регистраций. URL — это весь доступ.
- **Три уровня доступа.** Публичная ссылка (только смотреть), редакторская (управлять комнатой), персональная (вносить свои деньги, не трогая чужое).
- **Живое обновление.** SignalR синхронизирует траты между всеми открытыми вкладками без перезагрузки.
- **Тёмная тема.** Переключение в один клик, сохраняется в браузере. Применяется мгновенно — никакой белой вспышки при загрузке.
- **История и откат.** Ошиблись при вводе? Отмените любую операцию в один клик — «НаБрата» пересчитает баланс автоматически.
- **Предпросмотр дележа.** Перед разделением счёта видно, сколько достанется каждому из выбранных.
- **Защита паролем.** Заблокируйте комнату, чтобы никто случайно не удалил данные или не поменял настройки.
- **Предоплаты (авансы).** Участники вносят свои деньги через персональные ссылки, не дожидаясь итогового расчёта.

## Разработка

### Требования

- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
- SQLite уже встроен — дополнительной настройки не нужно.

### Запуск

1. Склонируйте репозиторий.

2. Настройте подключение к базе. В репозитории строка подключения — заглушка, поэтому создайте локальный dev-конфиг с указанием на SQLite-файл:

   ```json
   // src/EvenSteven.Api/appsettings.Development.json
   {
     "ConnectionStrings": {
       "db-connection": "Data Source=../../../../application.db;"
     }
   }
   ```

   *Путь относительный к рабочей директории. При запуске API из корня репозитория база создастся там же как `application.db`.*

3. Запустите API:

   ```bash
   dotnet run --project src/EvenSteven.Api
   ```

   Миграции (FluentMigrator) применяются автоматически при старте и при необходимости создают `application.db`.

4. Запустите клиент (в отдельном терминале):

   ```bash
   dotnet run --project src/EvenSteven.BlazorWeb
   ```

> Никогда не коммитьте `appsettings.*.json` с реальными секретами — продовые строки и ключи хранятся в переменных окружения или в локальном `appsettings.Production.json`.

### Тесты

Тестовый проект ([`tests/EvenSteven.RepositoryTests`](tests/EvenSteven.RepositoryTests)) на xUnit v3 поверх **Microsoft.Testing.Platform**. Каждый прогон создаёт собственную одноразовую SQLite-базу в папке `Test Databases` проекта — подготовка не требуется.

Запуск тестов:

```bash
dotnet test --project tests/EvenSteven.RepositoryTests
```

### Коммиты

Мы следуем [Conventional Commits](https://www.conventionalcommits.org/) — короткий субъект в повелительном наклонении с префиксом-типом и опциональным scope.

Примеры:

- `feat: add room expenses API`
- `feat(room): add participant keys`
- `fix: reset room balance on undo`
- `docs: update ADR-001`
- `refactor: extract BruteForceGuard`
- `test: cover settlement calculation`

Правила: один логический изменение на коммит, субъект до 72 символов, повелительное наклонение; при необходимости ссылка на issue/PR в теле (`closes #12`).
